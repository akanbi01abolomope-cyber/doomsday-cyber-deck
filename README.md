# doomsday-cyber-deck
🖥️ Doomsday Cyberdeck is an ambitious portable, rugged computer project featuring local AI (A.D.A.), offline maps and GPS, radio, expandable storage, custom CAD designs, and PCBs. 🛠️ Follow the development journey from software setup and hardware design to testing and assembly, with a focus on offline capability, reliability, and modularity. 🚀
