# Release status — Rev 1.0 design candidate

This package is a cleaned-up and better-documented design candidate, not a production release.

## Ready to inspect
- Parametric OpenSCAD enclosure source
- Enclosure target dimensions and fit-check notes
- KiCad front-panel PCB concept source
- BOM and proposed connector pinout

## Not yet ready for fabrication
- No exact component models/dimensions have been confirmed
- No verified complete mechanical assembly or STEP export
- PCB has no verified schematic and completed copper routing
- Footprints and pin mapping have not been checked against selected physical parts
- No Gerber/drill package has been released
- No electrical, thermal, mechanical, or runtime tests have been performed

A true final release depends on choosing exact components and validating the design against their datasheets and physical measurements. Do not treat this package as proof that the cyberdeck is ready to build.
