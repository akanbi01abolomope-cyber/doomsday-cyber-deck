# CAD Rev 1.0 — Design Candidate

## Files
- `cyberdeck_rev1.scad` — editable parametric enclosure concept with base, lid, mounting plate, drive cradle, and assembly preview.
- `dimensions_and_checks.md` — current assumptions and checks required before manufacture.

## Open / export
1. Install OpenSCAD.
2. Open `cyberdeck_rev1.scad`.
3. Set `part` near the top to `base`, `lid`, `plate`, or `drive_cradle` to render one part.
4. Press F6 to render, then use File → Export → Export as STL.

This bundle intentionally does not include fabricated STLs or STEP files because those exports need to be generated and inspected from the actual chosen component dimensions.
